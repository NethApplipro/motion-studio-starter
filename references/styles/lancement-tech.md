# lancement-tech

**En une phrase :** film de lancement « outil pour développeurs » : rapide, précis, chaque transition démontre une fonction (un signal qui se ramifie, un flux qui se transforme, un flux interrompu qui reprend).
**Idéal pour :** copilote RH IA, connecteurs SIRH, API, marque blanche, partenaires intégrateurs.
**Source :** prompt TanStack AI de @HowDevelop (voir `../prompts/lancement-tech-howdevelop.md`).

## Grammaire
- **Fond :** graphite sombre `#121624` avec dégradés lumineux contrôlés issus de la marque (`#3374FF` → `#0E0E52`).
- **Typographie :** nette, contrastée, mots à l'écran très courts ; code ou données « cinétiques » lisibles (jamais du code minuscule).
- **Éléments :** fragments d'interface en couches, flux de données, chemins qui se ramifient, nœuds qui se connectent.
- **Caméra :** mouvements fluides avec une vraie profondeur (parallaxe entre couches).
- **Transitions :** **chaque transition montre une fonctionnalité** au lieu de remplacer un carton par un autre.
- **Son :** pulsation d'ouverture retenue, impacts serrés sur les transitions, montée, résolution satisfaisante ; le film doit marcher sans le son.
- **Garde-fous d'exactitude :** ne présenter que ce qui est livré (pas les fonctions prévues).

## Exemple Nova (15 s)
Curseur de recherche → « Une question RH ? » → le signal parcourt le livret d'accueil (rubriques qui s'allument) →
réponse sourcée « se rendre à la page : Paie » → les connecteurs SIRH se branchent autour → « Nova · le point d'entrée du salarié ».

## Interdits spécifiques
Images de stock, logo qui tourne, faux dashboards, glitch excessif, code illisible.
