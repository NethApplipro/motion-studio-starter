# Vos captures produit
Déposer ici les captures autorisées du produit à présenter. Ajouter chaque écran redessiné à `src/components/app/catalog.ts` avec le nom de sa capture et ses états.
La maquette initiale Nova est fictive ; elle ne décrit aucun produit réel. Les captures Applipro ne sont pas distribuées dans ce starter.
