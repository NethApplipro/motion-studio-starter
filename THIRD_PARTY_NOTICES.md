# Ressources et dépendances tierces

Le code du studio provient du dépôt de NethApplipro, exporté au commit b6b6c8f. La licence MIT de ce starter couvre le code dont l'auteur dispose des droits, pas les marques ni les ressources tierces.

- Remotion : https://www.remotion.dev/docs/license — conditions distinctes de MIT, à vérifier selon l'usage.
- Poppins : polices distribuées sous SIL Open Font License. Notice complète dans `public/fonts/OFL.txt`.
- Remix Icon : conserver sa notice dans `src/components/app/REMIXICON-LICENSE.txt` pour les tracés générés.
- Sons de synthèse : origine documentée dans `public/audio/LICENCES.md` ; générables via `npm run sfx`.
- Dépendances npm : versions dans `package-lock.json`, licences dans les paquets correspondants.
- Références créatives : liens et crédits dans `references/`. Les vidéos et identités des auteurs ne sont pas incluses et ne sont pas automatiquement réutilisables.

Le nom et le symbole Nova servent uniquement de démonstration ; aucune disponibilité commerciale de ce nom n'est garantie.
